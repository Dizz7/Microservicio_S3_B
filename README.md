# Microservicio_S3_B
Actividad de semana 8 del curso Fullstack I - Microservicio Proyecto B

Microservicio de Pacientes desarrollado con Spring Boot.

Incluye:

Operaciones para crear, consultar, actualizar y eliminar pacientes.

Conexión a Oracle Autonomous Database.

Configuración para ejecutar con Docker Compose.

Para ejecutar el archivo JAR se requiere una versión compatible de Java y configurar las credenciales y la ubicación del wallet de Oracle.

Este proyecto fue desarrollado como una actividad de carácter educativo para practicar el desarrollo de microservicios con Spring Boot, la conexión a Oracle y el uso de Docker. No está destinado a su uso en producción.
